# Centro de Inteligencia Artificial Bravo
## Proyecto: Física sin Herencia

Una mente que descubre las leyes del universo desde cero — sin conocimiento humano, sin internet, sin palabras. Solo datos crudos, 30 reglas, jueces intocables y un árbol de conocimiento que crece.

Fundado por **Leo Bravo** (director) con Claude como orquestador fundador — julio de 2026.

## Los tres documentos del alma (leer en este orden)
1. **`CIMIENTOS.md`** — las 30 reglas del método, la Segunda Ciencia, el prompt de arranque para cualquier orquestador.
2. **`MENTE.md`** — la identidad y experiencia del científico (v10): quién es, qué aprendió, dónde va.
3. **`GUIA-ORQUESTADOR.md`** — el manual de relevo: prohibiciones eternas, lecciones pagadas, trampas técnicas, sistemas vivos.


## Política de datos (12-jul-2026)
**El repositorio es para código, reglas, registros y conocimiento — NO para datos pesados.** Los datos crudos y procesados (videos, extracciones, modelos .pt) viven en la carpeta local `datos/` (ignorada por git) con doble respaldo: OneDrive (continuo) y la copia fría `C:\FisicaSinHerencia-Respaldo` (semanal, fuera de la nube). Cada dataset está documentado con procedencia y licencia en su prerregistro.
